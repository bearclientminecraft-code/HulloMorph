# Chad Morph Android v0.4 — Target Geometry Engine

## Что нового
- `MorphConfig` — нормализованная конфигурация (0..1): раздельно лево/право (`SideParams`: jaw, gonial,
  hollow, bone, tilt, lidDrop, lowerLid) + chin projection/width, symmetry, strength; физические максимумы в `MorphLimits`.
- `ReferenceProfile`/`FaceMetrics` — пропорции из референс-фото (челюсть, угол gonion, щёки, canthal tilt,
  раскрытие глаз, подбородок). Параметр = доля пути «исходник → референс», в пределах `MorphLimits`.
- `FaceGeometry` — система координат лица (roll по линии глаз), оценка yaw/pitch (z-координаты MediaPipe + 2D по носу), метрики.
- `FaceMorphEngine` — 56 контрольных landmarks (контур челюсти, gonion, подбородок, щёки, скулы, веки, углы глаз, якоря рта),
  смещения в плоскости лица → проекция позы → EMA-сглаживание.
- `DeformationMesh` — сетка 64×64 над ROI лица, обратное отображение, защита от складок/растяжения
  (отношение площадей треугольников ∈ [0.35, 2.5], локальный масштаб Λ, сглаживание, ограничение скорости роста, финальная гарантия).
- GPU: шейдер только сэмплит текстуру; сетка рисуется `glDrawElements`. Никаких теней/бликов.
- `MeshDebugOverlay` — PNG до/после (кнопка «Debug: сетка до/после»).
- Unit-тесты: `app/src/test/.../DeformationStabilityTest.kt` (JUnit4, синтетическое лицо).

## Интеграция
Файлы лежат в `com.chadmorph`. Пайплайн: `VideoMorphProcessor.process(uri, out, config, reference, debug, maxDurationUs, ...)`.
Свой код: `FaceMorphEngine().build(trk.pts, w, h, cfg, trk.strength, trk.dtSec, ref, field)` → `DeformationMesh().update(field, w, h)`
→ `GlMorphRenderer.renderFinal(mesh, ptsUs)`.

## Честный статус
ПРОВЕРЕНО (Python-порт той же математики на синтетических landmarks, 1080×1920):
 - нет складок/сверхрастяжения при Extreme, при yaw до 60°, pitch ±25°, roll ±30° (по площадям треугольников сетки);
 - независимость лево/право; идемпотентность self-reference; симметрия снижает асимметрию пар; эквивариантность к сдвигу;
 - чувствительность к шуму landmarks (σ=1px → сдвиг источника ≤ ~3.4px).
НЕ ПРОВЕРЕНО: компиляция Kotlin, запуск Kotlin unit-тестов (они написаны, но не запускались), GL/MediaCodec/экспорт,
MediaPipe на реальных лицах, поведение на Realme C25 (скорость/нагрев), визуальное качество.
Тесты используют синтетическое лицо; Kotlin-код — перенос Python-порта вручную, расхождения возможны.

## Ограничения (не скрываем)
- 2D-варп НЕ создаёт 3D-объём. «Cheekbones»/«hollow» — только геометрия контуров; без теней/бликов.
- Yaw/pitch — приближённая оценка (z MediaPipe предсказан моделью). Метрики референса достоверны при почти анфас.
- «Extreme» реально ограничивается защитой от складок (Λ<1) — смотри min Λ в статусе.
- Hunter eyes: canthal tilt + опускание верхнего/подъём нижнего века (пропорционально раскрытию); брови, форма радужки, 3D-глубина не меняются.
- Одно лицо; профиль/сильный поворот → эффект гаснет.
